# Log trap

Add one entry to `<VAULTS>/Roblox Knowledge/rules/traps.md`.

1. Read the file and copy its own entry format: date, what broke, fix, reason.
2. Fill it from $ARGUMENTS and this session. Ask the dev for any part you
   don't know; don't guess the reason.
3. Append it at the bottom, newest last. Change no other entry.
