# Learn

1. Read `.roblox-ai/ledger.jsonl` in the game repo. If it is missing or
   empty, say so and stop.
2. Read `<VAULTS>/Roblox Knowledge/rules/recipes.md`.
3. Find what keeps scoring low or getting fixed, and draft recipes that would
   have got it right first time. Merge with existing recipes; don't duplicate.
4. Show the dev the exact change to `recipes.md` and wait.
5. Write it only after the dev says yes.
